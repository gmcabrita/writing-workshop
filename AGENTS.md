# AGENTS.md

## Effect

This project uses Effect v4 (`effect@^4`). Its APIs differ a lot from Effect v3, so do not rely on v3 knowledge or outside docs.

Before writing or changing Effect code, read `node_modules/effect/AGENTS.md`. For examples, see `node_modules/effect/ai-docs/src/` and the package source in `node_modules/effect/src/`.

## Checks

Run `pnpm check` (typecheck, format check, and lint) before finishing a change.
